# @njord/tokens

The single source of truth for the NJORD design system. Every colour, type
role, radius and shadow is declared here once, and every build reads a
generated artefact rather than its own copy.

```
src/            ← the source. Edit these.
  color.ts        palette, status tints, severity ramp, fluids, SCADA
  typography.ts   families, the semantic type scale, mobile overrides
  layout.ts       radii, elevation
  themes.ts       the runtime alias layer and the three skins
  css.ts          the emit map — what each token is CALLED in CSS
dist/           ← generated by `npm run build`. Never edit.
  index.js        typed values for JS/TS consumers
  tokens.css      Tailwind v4 @theme + alias layer + skins (web build)
  njord.css       the Ignition Perspective gateway theme (--njord-*)
  njord-theme.js  the same CSS as a string, so the docs can render it
  tokens.json     a flat name → value map for anything else
```

## Consuming it

```ts
import { palette, severity, skins } from '@njord/tokens'
```

```css
@import "tailwindcss";
@import "@njord/tokens/css";
```

For Ignition, deploy `dist/njord.css` to
`$IGNITION/data/modules/com.inductiveautomation.perspective/themes/njord.css`
and set the project theme to `njord`.

## Changing a value

1. Edit the value in `src/`.
2. `npm run build` (from the repo root, or in this package).
3. Commit the `src/` change. `dist/` is generated and gitignored.

The web build, the TypeScript exports and the HMI theme all move together —
there is no second place to remember.

## Adding a token

Add the value to the right `src/` module, then give it a CSS name in
`src/css.ts`. Leave `ignition` off if the HMI has no counterpart. The build
fails on a duplicated name or a colour that is not a 6-digit hex.

## Naming

Web and Ignition use the same names behind different prefixes, so a token is
greppable across both codebases:

| Web              | Ignition           |
| ---------------- | ------------------ |
| `--color-primary`| `--njord-primary`  |
| `--color-sev-crit`| `--njord-sev-crit`|
| `--radius-md`    | `--njord-r-md`     |
| `--shadow-base`  | `--njord-shadow`   |
| `--font-sans`    | `--njord-font-sans`|
